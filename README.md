# vibe-coded-housekeeping-tools
Some vibe coded housekeeping tools for PhD daily lab housekeeping.

## Tools

- [Experiment Roadmap](experiment-roadmap/): plan parallel wet-lab experiments day by day, tick off steps, keep daily notes and export a lab notebook. Data is saved per user and synced.
- [Figure Pipeline](figure-pipeline/) (planned): link Adobe Illustrator and Google Docs to automate figure legends, in-text figure numbering, figure layout and journal-ready submission folders. See the [roadmap](figure-pipeline/ROADMAP.md).
